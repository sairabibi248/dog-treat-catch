# 🐕 Dog Treat Catch 🍖 — Canvas Arcade Game

An interactive, responsive HTML5 Canvas arcade game built for the **DEV Weekend Challenge: Dog Days Edition**. Players control a hungry puppy to catch treats, collect power-ups, avoid hazardous items, and progress through 5 dynamic levels!

---

## 🐶 Key Features

* **🦮 Custom Dog Characters:** Choose your favorite puppy (Golden Retriever, Happy Dog, Cute Puppy, or Poodle).
* **🏆 5 Progressive Levels:** Unique background themes, increasing difficulty, and dynamic target scores.
* **⚡ Power-Ups & 💣 Hazards:** Catch bones, meat, and bacon while avoiding chocolates, candies, and bombs. Collect Shields and 2x Score Multipliers!
* **🔊 Zero-Dependency Web Audio:** Built-in dynamic sound effects created entirely with the browser's Web Audio API (no external audio files needed).
* **💾 High Score Tracking:** LocalStorage integration to save your best scores across sessions.
* **🕹️ Smooth 60FPS Gameplay:** Powered by HTML5 Canvas `requestAnimationFrame` for super smooth animations.

---

## 🛠️ Tech Stack

* **🎨 Frontend:** HTML5, Pure CSS3
* **🧠 Game Logic:** Modern Vanilla JavaScript (ES6+)
* **🖼️ Graphics:** HTML5 Canvas API
* **🎵 Audio System:** Web Audio API (Synthesized SFX)

---

## 🎮 How to Play

1. **🐾 Move:** Use your mouse or Touch controls to move the puppy left and right.
2. **🦴 Catch:** Grab bones (+10 pts), meat (+20 pts), and bacon (+30 pts).
3. **🍫 Avoid:** Stay away from chocolates (-15 pts) and hazards!
4. **🎯 Win:** Reach the level score target before running out of lives to advance to the next level.
